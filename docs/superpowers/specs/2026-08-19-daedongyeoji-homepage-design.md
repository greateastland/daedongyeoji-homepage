## 사이트 구조 (원페이지 스크롤, 단일 HTML)

상단 고정 네비게이션: 로고(대동여지) + 섹션 앵커 링크 + 연락처 버튼.

1. **Hero** — 다크 톤. 지도 텍스처 느낌의 배경(SVG/CSS 패턴으로 재현, PDF 이미지 직접 사용 안 함 — 저작권/용량 이슈 회피). 카피: "Comm. Solution Agency / 대동여지" + "Beyond Communications, We Forge Custom-made Solutions."
2. **회사소개 (Our Origin / Mission)** — 다크 톤 유지. 대동여지도 모티브 설명, 미션 문구.
3. **사업영역 5개** — 밝은 톤으로 전환. 카드 5개:
   - 브랜드전략 및 광고제작 (BTL/Event/PR 연동)
   - 매체구매대행 (Media Buying Rep, 3% 이상 Benefit)
   - New Media (LED On-Road 옥외 버스광고 HESTIA)

4. **대표 레퍼런스** — 카드 그리드. 브랜드명 + 캠페인명 + 성과 한 줄(PDF 문구 그대로 인용). 예:

   - 한국인삼공사 정관장 — "'홍삼=면역력'으로 기대 효능 확대 (전년대비 약 120% 매출)"
   - 이니스프리, LG전자, KT, 기아자동차, 데상트코리아 등 텍스트 카드로 보강
5. **클라이언트 로고/텍스트 리스트** — LG전자, KT, 기아자동차, 데상트코리아, 대웅제약, 유한양행, 한국인삼공사, 신한은행, 금호아시아나, 대우건설, 올림푸스, 대상 등 텍스트 나열.

## 기술 스택
빌드 도구 없는 순수 HTML/CSS/JS 정적 사이트 3파일 구성:
- `index.html`
- `style.css`
- `script.js` (모바일 메뉴 토글, 스무스 스크롤 정도의 최소 기능)

프레임워크/패키지 매니저 불필요. 파일을 직접 열어도 동작 확인 가능.

## 무료 배포
GitHub(무료 코드 저장소) + Vercel(무료 정적 호스팅) 조합.
- 사용자가 GitHub 계정 생성 → 이 프로젝트를 리포지토리로 push
- Vercel 계정 생성(GitHub 로그인 연동) → 리포지토리 연결 → 자동 배포
- 이후 코드가 GitHub에 push될 때마다 Vercel이 자동 재배포
- 주소: 무료 서브도메인 (예: `daedongyeoji.vercel.app`), 커스텀 도메인은 추후 필요시 유료 연결 가능(현재는 미적용)
- 필요한 등록: GitHub 계정, Vercel 계정 (둘 다 무료 가입). 사업자등록 등 그 외 등록 불필요.
